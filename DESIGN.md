# Design Brief — TrekRoots | TR Yellow

## Brand
**TREKROOTS** wordmark: yellow **TREK**, dark **ROOTS** with white hiker in the O, tagline “EXPLORE • DISCOVER • CONNECT.”

## Color Palette
| Use | Hex | Purpose |
|---|---|---|
| Primary Background | #FFFFFF | Page canvas, navbar |
| Secondary Surface | #F5F5F5 | Cards, panels |
| Brand Accent | #FFC107 | CTAs, active nav, highlights |
| Bright Accent | #FFD54F | Hover / secondary highlights |
| Soft Accent | #FFE082 | Badges, soft fills |
| Text Primary | #1A1A1A | Headings, body |
| Text Secondary | #666666 | Supporting copy |
| Border | #E8E8E8 | Dividers |
| Logo / Footer field | #000000 | Logo plate, footer |

## Buttons
Retro offset shadow: 2px black border + 4px hard offset; hover compresses to 2px.

## Typography
Plus Jakarta Sans for display and body; JetBrains Mono for stats.
